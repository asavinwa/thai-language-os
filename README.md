# Thai Language OS

A personal system for turning everyday life into practical Thai.

The goal is not to collect vocabulary.

The goal is to make useful Thai automatic through capture, speaking, correction and repetition.

## Current priorities

- Speak more Thai with family
- Think in Thai during everyday activities
- Build confidence speaking without translating
- Develop practical vocabulary around boxing, food, football and travel

## How the system works

1. Capture useful Thai from real life.
2. Correct mistakes and improve phrasing.
3. Practise a small number of phrases repeatedly.
4. Use Thai through speaking, writing and everyday interactions.
5. Move phrases into the owned list once they feel automatic.

## Core files

- `phrases/phrases-i-want-to-own.md` — the active phrases I want to make automatic
- `daily/` — short daily entries, corrections and practice targets
- `ADD-SONG-WORKFLOW.md` — canonical end-to-end workflow whenever a song is added
- `SONG-LESSON-RULES.md` — detailed rules for full guided song lessons
- `STORY-RULES.md` — detailed rules for interactive stories, including stories built from songs

## Adding a song

When the user asks to **add a song**, follow `ADD-SONG-WORKFLOW.md` rather than designing the experience from scratch.

A fully added song normally means:

1. Build the full interactive guided song lesson in the existing format.
2. Add it to the songs index.
3. Build an original story reusing the song's strongest language patterns.
4. Add the story to the stories index.
5. Cross-link the song and story.
6. Check both against existing canonical examples before saying the work is complete.

Lyrics can be supplied by the site owner or researched from reliable sources. Do not invent missing lyrics. Respect copyright constraints; if a complete line-by-line lesson needs source text that cannot appropriately be reproduced from an external source, ask the user to supply the lyrics.

## Story length

Song-derived stories should follow the established interactive story format and normally contain at least 12 guided sentences. Twelve is a minimum, not a fixed template: stories should run as long as needed for a coherent narrative and useful language practice.
